# Ego Lite：使用与测试范围

记录日期：2026-11-04。依据本机 `ego-browser skill` 显示的 v2.2.0 指南和本次浏览器使用观察；并非完整功能测试。

## 目前了解到的工作方式

Ego Lite 提供 TaskSpace 与浏览器页面，Agent 可以读取页面快照、按元素或坐标操作，并在需要用户完成登录、验证或其他敏感步骤时交还控制权。指南还描述下载、截图和页面代码等接口。具体可用性取决于安装版本、页面和账户状态。

## 本次观察

- 浏览器能够进入已登录服务，并通过页面导航、输入与快照读取完成一次网站指标查看。
- 登录、用户接管与页面加载会影响任务流程；操作回执本身不能代替检查页面实际结果。
- 本次观察没有建立跨网站成功率、速度或稳定性的对照实验，也不能说明所有网站都允许自动化操作。

## 后续测试

- 在明确允许的测试站点，验证页面导航、表单、下载和多标签流程。
- 测量页面加载、操作失败、重试及用户接管后的恢复表现。
- 将结果与可用的官方 API 或连接器比较，记录适用场景和限制。
